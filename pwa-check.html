On Android Chrome

Open the app in Chrome (not an in-app browser). Tap ⋮ → Install app or Add to Home screen. If Chrome says “already installed” but Android cannot find or launch it, this can be a stale Chrome/Android installation record; repeatedly creating shortcuts will not repair it.

Do not clear Chrome storage or uninstall other working apps. If needed, search the Android app drawer and Settings → Apps for this app's short name.
